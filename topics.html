Tech Topics to Explore

Technology is constantly changing, and staying informed about emerging fields is an essential part of my academic development in Information Technology. Below are key technical domains that I plan to research, master, and apply to future projects.

1. Cloud Computing & Infrastructure

Modern businesses rely on the scalable cloud services to manage their data and to deploy software applications on a global scale. Understanding how the cloud resources are supplied/secured is one of my main goals as an IT student.

  • Concepts: Cloud storage, virtual machines, serverless technology.
  • To Learn: Amazon Web Services and Microsoft Azure.
  • Goal: Deploy static websites + dynamic web apps directly to cloud servers.

2. Cybersecurity & Information Assurance

Cybersecurity is my primary area of interest in Information Technology. Such as the securing of digital infrastructure, defending systems against vulnerabilities, and protecting user privacy, are the critical requirements for modern web applications/organizational networks.

  • Domains: Network security, ethical hacking, identity management.
  • Practices: Encryption standards, secure authentication, firewalls.
  • Goal: Build secure web applications and pursue industry certifications in computer security.
